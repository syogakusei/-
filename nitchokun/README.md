# 日調くん

候補日を選んでリンクを送るだけの日程調整アプリ。30分ごとに 〇 △ × で回答でき、マスごとにコメントもつけられます。

## できること
- イベント作成：イベント名・説明・候補日（カレンダーでタップ／ドラッグ選択）・想定時間（「一日（日にちで調整）」または30分〜23時間30分）・時間帯
- 「一日」を選ぶと日にち単位のイベントになり、候補日ごとに 〇△× を1つ選ぶ（時間帯の入力は不要）。結果には「都合のいい日」ベスト3
- 時間単位のイベントでは、個人の予定の日付をタップするとその日の全マスをまとめて入力できる（消しゴムなら全部消える）
- 調整画面の上に 想定時間を表示。個人の予定・みんなの予定は30分ごと
- みんなの予定の下に「最適な時間」：想定時間（初期値は作成時の設定）を選ぶと、その長さで都合のいい枠ベスト3を表示。枠内が全部〇→〇、〇と△だけ→△、×が1つでも→×として数える。選んだ 想定時間はその画面だけで、保存はされない
- 回答：名前を入れて「はじめる」→ 〇 / △ / × / 消しゴムをドラッグで塗る。「💬 コメント」でマスごとにコメント
- 自動保存。「✓ 登録を完了して次の人へ」で入力欄がリセットされ、1台で何人分でも続けて登録できる
- 登録済みの人は名前チップをタップすると編集・名前変更・削除ができる
- 〇=1、△=0.5 で色の濃さを表示。マスや最適な時間を選ぶと誰が〇△×か・コメントが見られる
- 8秒ごとに他の人の回答を自動で取り込む
- 「📅 Googleカレンダーに追加」：最適な時間の候補と詳細欄から、タイトル・日時入りの予定作成画面を開く（API・審査不要）
- 「📅 Googleカレンダーの予定を重ねて表示」：個人の予定の表に、その人の Google カレンダー（メイン）の予定を半透明で重ねる。読み取りのみ（calendar.events.readonly）で、予定はブラウザ内に表示するだけで保存・共有しない。`index.html` の `GOOGLE_CLIENT_ID` を設定したときだけ表示される

## セットアップ
1. 日調くん専用の Supabase プロジェクトの SQL Editor で `schema.sql` を実行する（接続先は `index.html` の `SUPABASE_URL` / `SUPABASE_ANON_KEY`）
   - 以前の `schema.sql` を実行済みの場合は、代わりに `migrate-001-mtg-duration.sql` → `migrate-002-flexible-start.sql` の順に1回ずつ実行する（001 実行済みなら 002 だけ）
2. `index.html` を公開する
   - 今の Netlify サイトのままなら `/nitchokun/` で開ける
   - 独立したサイトにしたい場合は、Netlify で新しいサイトを作り Base directory を `nitchokun` にする

Supabase に接続できない場合は自動で「デモモード」になり、データはそのブラウザにだけ保存されます（画面上部に表示されます）。
