# 日調くん

候補日を選んでリンクを送るだけの日程調整アプリ。30分ごとに 〇 △ × で回答でき、マスごとにコメントもつけられます。

## できること
- イベント作成：イベント名・説明・候補日（カレンダーでタップ／ドラッグ選択）・MTG時間（30分〜丸一日、30分単位）・時間帯
- 調整画面の1マス＝「その時刻に始まる MTG時間ぶんの枠」。開始時刻は時間帯の中で30分刻み（例：9:00〜15:00・5時間 → 9:00 / 9:30 / 10:00 開始）
- 回答：名前を入れて「はじめる」→ 〇 / △ / × / 消しゴムをドラッグで塗る。「💬 コメント」でマスごとにコメント
- 自動保存。「✓ 登録を完了して次の人へ」で入力欄がリセットされ、1台で何人分でも続けて登録できる
- 登録済みの人は名前チップをタップすると編集・名前変更・削除ができる
- みんなの予定：〇=1、△=0.5 で色の濃さを表示。マスを選ぶと誰が〇△×か・コメントが見られる。都合のいい時間ベスト3も表示
- 8秒ごとに他の人の回答を自動で取り込む

## セットアップ
1. 日調くん専用の Supabase プロジェクトの SQL Editor で `schema.sql` を実行する（接続先は `index.html` の `SUPABASE_URL` / `SUPABASE_ANON_KEY`）
   - 以前の `schema.sql` を実行済みの場合は、代わりに `migrate-001-mtg-duration.sql` → `migrate-002-flexible-start.sql` の順に1回ずつ実行する（001 実行済みなら 002 だけ）
2. `index.html` を公開する
   - 今の Netlify サイトのままなら `/nitchokun/` で開ける
   - 独立したサイトにしたい場合は、Netlify で新しいサイトを作り Base directory を `nitchokun` にする

Supabase に接続できない場合は自動で「デモモード」になり、データはそのブラウザにだけ保存されます（画面上部に表示されます）。
